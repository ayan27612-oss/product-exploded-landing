# Product Exploded Landing

A premium one-page product showcase built with HTML, CSS and vanilla JavaScript.

## Animation
The exploded-view sequence expects 298 JPG frames at:

`assets/frames/ezgif-frame-001.jpg` through `ezgif-frame-298.jpg`

The product animation is mapped to scroll position using a canvas for smoother rendering and fewer DOM nodes.

## Run
Serve the project from a local web server or deploy directly to Vercel/GitHub Pages.
